# Archivo histórico

Cada estudio conserva su documentación, imágenes y archivos fuente. Para el estado actual del prototipo, consulta el [índice de ingeniería](../docs/INDICE_PROYECTO.md).

| Dónde buscar | Contenido |
| --- | --- |
| [CAD M1](cad/README.md) | Diseño paramétrico, bocetos y exportaciones de la primera arquitectura. |
| [Fusion M2, estudios del 2 y 3 de noviembre](cad/fusion_m2/) | Revisiones de encaje, fijaciones, tapas, PCB, montaje, variantes de aro y modelos comerciales. Antes estaban junto al CAD vigente en `cad/fusion_m2/`. |
| [Montaje animado del 3 de noviembre](cad/fusion_m2/animacion/README.md) | [Vídeo](cad/fusion_m2/animacion/CROSS_MONTAJE_ORDEN_REAL_2026-11-03.mp4), [secuencia de montaje](cad/fusion_m2/animacion/MONTAJE_PASO_A_PASO.md), fuentes y comprobaciones. Corresponde a la revisión mecánica de esa fecha. |
| [Documentos de concepto](docs/) | Implantaciones de acrílico y PVC, estudios de cierre, dibujos y renders. |
| [Electrónica](electronica/) | Arquitectura M1, propuesta eléctrica V1 e informes de la primera revisión de V8. Las copias de seguridad de KiCad se conservan comprimidas. El generador de esquema depende de la V7 retirada al historial de Git y de archivos de trabajo en `/tmp`. |
| [Compras](compras/) | Lista amplia histórica, copia del Excel que antes estaba en la raíz y datos de inspección de la hoja. El [Excel enlazado por la lista de compra](../compras/Cruz_Shopping_List_EN_2026-10-30.xlsx) está en `compras/` en la raíz. |
| [Resumen anterior del repo](RESUMEN_2026-11-08.md) | Portada anterior, con el estado y diagramas de aquella etapa. |

Los nombres de ruta dentro de informes JSON registran la ubicación histórica de sus archivos cuando se generaron. Los scripts de Fusion corresponden a estudios de aquella etapa y algunos modifican el documento que esté abierto.
